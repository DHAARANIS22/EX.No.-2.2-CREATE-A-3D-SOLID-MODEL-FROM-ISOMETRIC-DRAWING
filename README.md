# EX.No.-2.2 CREATE A 3D SOLID MODEL FROM ISOMETRIC DRAWING
## Date :14-10-2026

## AIM: 

To create a 3Dmodel from the given isometric drawing using fusion 360 tool. 

## REQUIREMENTS:
1. Autodesk fusion 360
2. Windows 10
3. 16 GB of RAM (integrated graphics recommend 1 GB or more)
4. 2.5 Mbps or faster download; 500 Kbps or faster upload 

## PROCEDURE


1. Open Autodesk Fusion 360 and create a new design.

2. Select the **Create Sketch** option and choose the XY plane.
   <img width="442" height="653" alt="Screenshot 2026-11-16 010723" src="https://github.com/user-attachments/assets/d2cabf5c-3ebd-4437-bca1-188a475151d1" />


4. Use the **Line** and **Rectangle** tools to draw the base profile according to the given dimensions.
   <img width="51" height="51" alt="Screenshot 2026-11-16 015231" src="https://github.com/user-attachments/assets/f1d02946-1214-4c60-a4ea-8cb358eec163" />
   <img width="43" height="46" alt="Screenshot 2026-11-16 014652" src="https://github.com/user-attachments/assets/878f1d9d-c655-4102-a224-ebffa612e2ed" />



6. Use the **Arc** tool to create the rounded ends of the base.
<img width="192" height="82" alt="image" src="https://github.com/user-attachments/assets/9895ab97-afa0-4684-9215-39ef65533ce7" />

7. Select the **Circle** tool and draw the required circular holes on the base.
 <img width="52" height="46" alt="Screenshot 2026-11-16 014634" src="https://github.com/user-attachments/assets/578ea852-731c-404a-881e-c3561b04689b" />


9. Apply the **Dimension (D)** tool to specify the required measurements and diameters.
    <img width="70" height="57" alt="Screenshot 2026-11-16 014210" src="https://github.com/user-attachments/assets/36a9192c-e63b-45e2-ae84-f7b97ed64081" />


11. Click on **Finish Sketch** to complete the base sketch.
    <img width="142" height="66" alt="Screenshot 2026-11-16 015045" src="https://github.com/user-attachments/assets/1f975f1b-f1f5-4614-81d5-b2620910dc60" />


13. Select the **Extrude** tool and give the required thickness of 10 mm to create the base solid.
    <img width="305" height="341" alt="Screenshot 2026-11-16 021239" src="https://github.com/user-attachments/assets/7841e8bb-68ee-4f36-bbee-b74b8b7ef95a" />


15. Create another sketch on the required face and draw the vertical support profile using the Line tool.

16. Use the **Extrude** tool to create the vertical supporting portion with the required height.

17. Draw the inclined supporting portion using the Line tool and create the required solid using Extrude.

18. Create a circular sketch on the upper portion and draw two concentric circles with the given diameters of 30 mm and 20 mm.

19. Use the **Extrude** tool to create the upper cylindrical portion with the required height.

20. Use the **Hole** or **Extrude Cut** tool to create the required circular holes.

21. Apply the required dimensions and check all the features according to the given isometric drawing.

22. Finally, save the completed 3D solid model in Autodesk Fusion 360.
